# 2026-08-23: Tier-0 indicators use semantic per-head chrome and presented capture

Historical source, not a current status claim. <a href="../../../history/research-log-2026-09-06.txt">Original snapshot</a>,
lines 15734–15767. The heading supplies the recorded date.

<!-- BEGIN IMPORTED BODY -->

The first retained-behavior row after the protected broker is implemented in
the Sophia candidate. A fixed 14-logical-pixel top reservation enters every
public `sophia_wm_v1` work area before the first snapshot and remains when
policy status clears. The committed descriptor becomes one private semantic
display-list node per logical output. Engine carries that node through damage
and per-head composition; the renderer rasterizes it at the head-native extent
instead of scaling a primary-output bar.

Text uses the included JetBrains Mono NL Regular 2.304 font, whose checked-in
bytes have SHA-256
`fb3b2575d7b0657359707993288f12a7360344d39387bb26050e276d61f6bd2a`,
under the included OFL. Parley performs layout and Vello CPU emits deterministic
XRGB pixels. A 128-entry, 16-MiB least-recently-used cache keys the complete
semantic strip; evicted rasters remain alive while an in-flight frame owns
their shared bytes.

Pointer selection uses the applicable output's last-presented strip projection.
An otherwise unowned primary press captures the exact seat, device, output,
presentation epoch, and descriptor target; only its matching in-target release
activates the opaque policy action. Existing application route leases and focus
handoffs keep ownership. Presentation, target, topology, seat, security, and
policy-restart changes cancel the chrome capture rather than transferring it.
The activation is dispatched against the clicked output, not the session's
default output.

Focused Engine, renderer, backend projection, and verifier-fixture tests pass.
The one-shot `tools/hagia-proof` guide now asks the operator, after the causal
Hagia restart, to confirm the strip above fullscreen, click view 2, and click
view 1 to return. The final verifier requires both indicator-origin activation
records and both committed actions. That signed physical run remains the
promotion boundary.

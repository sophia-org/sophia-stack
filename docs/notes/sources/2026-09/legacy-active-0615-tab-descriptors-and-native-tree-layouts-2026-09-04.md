The user selected the complete Hagia/Narthex feature slice independently of the
CP14 comparison. Triad baseline `fb8fb27ec294e0fe2361375de0b2fa8c08be0ca9`
supplies the private tree semantics; its compositor metadata/rendering ownership
is not copied. Notion uses the same native binary geometry rather than requiring
Janet. Tabbed and stacking containers retain horizontal strips.

Revision-3 WM layouts remain frozen: capability bit 11 admits uncounted group
and member projection extensions. Shell revision 2 adds bounded persistent
descriptor transfers while preserving revision-1 switcher messages. Geometry and
hidden-member eligibility remain in Sophia, recipient-local labels/actions in
Narthex, and topology in Hagia. GPU composition uses the existing rectangle and
cached-text primitives; no blind raster-content extension is added.

The lifecycle model passed 99 distinct states. Removing the freshness check
violated `CoherentPresentation`; retaining capture on shell loss violated
`ExactActivation`. These are model checks, not physical display acceptance.
See [tabbed layouts](../../../tabbed-layouts.md) for wire semantics and the operator gate.

Implementation is present in all three working repositories. Final verification
passed `cargo xtask check` (2,340 passing test executions, clippy, all 20 retained
archives, and host buffer-age pixel equivalence), both Sophia protocol gates,
Hagia's independent policy suite and source-layout gate, and Narthex's independent
shell suite and source-layout gate. Rust/C/Nim shell conformance covers persistent
tabs alongside the revision-1 switcher and reservation workflows. The immutable
revision-3 C WM client still passes all 11 behavior scenarios and restart.
Formatting and whitespace checks pass. Hagia checkpoint tests cover migration
from version 4 and exact version-5 round-trip of a populated tree.

No live desktop was restarted or installed for this slice. Physical tab rendering,
hidden-member input, multi-output retirement, and recovery acceptance remain
unrun. Client occlusion currently disables the whole overlapped tab target;
partial-target clipping is not implemented.
